# Change Navigation Checklist

**Purpose:** To systematically guide through analysis and planning when significant changes are identified during workflow.

## 1. CHANGE CONTEXT
- [ ] Change trigger clearly identified and documented
- [ ] Impact scope estimated (story/epic/project level)
- [ ] Urgency and priority assessed
- [ ] Stakeholders identified and notified

## 2. IMPACT ANALYSIS
- [ ] Affected epics and stories identified
- [ ] Architecture implications assessed
- [ ] PRD modifications required evaluated
- [ ] Timeline and resource impacts calculated

## 3. ARTIFACT CONFLICT RESOLUTION
- [ ] Conflicting requirements identified
- [ ] Dependencies analyzed
- [ ] Integration points reviewed
- [ ] Technical debt implications considered

## 4. PATH EVALUATION
- [ ] Multiple solution options evaluated
- [ ] Cost-benefit analysis completed
- [ ] Risk assessment conducted
- [ ] Recommended path forward defined

## 5. CHANGE PROPOSAL
- [ ] Detailed change proposal drafted
- [ ] Stakeholder approval obtained
- [ ] Implementation plan created
- [ ] Success criteria established
