🔥 Guia de Configuração Firebase

Configure em 5 minutos e comece a usar!

1

Acessar Firebase Console

Abra o navegador e acesse o Firebase Console:

🚀 Abrir Firebase Console

Faça login com sua conta Google (ou crie uma).

2

Criar Novo Projeto

No Firebase Console:

  • Clique em "Adicionar projeto" ou "Create a project"
  • Nome do projeto: evolveai-hackathon
  • Desabilite Google Analytics (não é necessário para este projeto)
  • Clique em "Criar projeto"
  • Aguarde alguns segundos até o projeto ser criado
⚠️ Nota: Se já tem um projeto Firebase, pode usar ele em vez de criar um novo.
3

Habilitar Firestore Database

No menu lateral do projeto, clique em "Firestore Database":

  • Clique em "Criar banco de dados"
  • Modo: Selecione "Modo de produção"
  • Local: Escolha "southamerica-east1 (São Paulo)"
  • Clique em "Ativar"
  • Aguarde alguns segundos até o banco ser criado
4

Habilitar Authentication

No menu lateral, clique em "Authentication":

  • Clique em "Começar" ou "Get started"
  • Na aba "Sign-in method", procure por "Email/Password"
  • Clique nele e ATIVE a opção
  • Clique em "Salvar"
5

Obter Credenciais do Firebase

Agora vamos copiar as credenciais:

  • No menu lateral, clique no ícone de engrenagem ⚙️ ao lado de "Visão geral do projeto"
  • Clique em "Configurações do projeto"
  • Role a página até a seção "Seus apps"
  • Clique no ícone "" (Web)
  • Nome do app: EvolveAI Hackathon
  • NÃO marque "Configure Firebase Hosting"
  • Clique em "Registrar app"

Você verá um código JavaScript parecido com este:

const firebaseConfig = {
  apiKey: "AIzaSyAbCdEfGhIjKlMnOpQrStUvWxYz1234567",
  authDomain: "evolveai-hackathon.firebaseapp.com",
  projectId: "evolveai-hackathon",
  storageBucket: "evolveai-hackathon.appspot.com",
  messagingSenderId: "123456789012",
  appId: "1:123456789012:web:abcdef1234567890"
};
⚠️ IMPORTANTE: Copie TODO o objeto firebaseConfig (as 6 linhas). Você vai precisar desses valores no próximo passo!
6

Configurar Aplicação

Agora vamos colocar as credenciais na aplicação:

  • No VS Code, abra o arquivo: src/firebase/config.js
  • Localize o trecho com os valores "YOUR_API_KEY_HERE"
  • Substitua TODOS os valores pelas credenciais que você copiou no passo anterior

Exemplo de ANTES (valores de exemplo):

const firebaseConfig = {
  apiKey: "YOUR_API_KEY_HERE", ❌
  authDomain: "evolveai-hackathon.firebaseapp.com",
  projectId: "evolveai-hackathon",
  storageBucket: "evolveai-hackathon.appspot.com",
  messagingSenderId: "123456789012",
  appId: "1:123456789012:web:abcdef1234567890"
};

Exemplo de DEPOIS (com suas credenciais reais):

const firebaseConfig = {
  apiKey: "AIzaSyAbCdEfGhIjKlMnOpQrStUvWxYz1234567", ✅
  authDomain: "seu-projeto-real.firebaseapp.com",
  projectId: "seu-projeto-real",
  storageBucket: "seu-projeto-real.appspot.com",
  messagingSenderId: "987654321098",
  appId: "1:987654321098:web:xyz9876543210"
};
⚠️ ATENÇÃO: Use os valores DO SEU PROJETO, não copie o exemplo acima!
7

Configurar Security Rules

Volte ao Firebase Console e configure as regras de segurança:

  • No menu lateral, clique em "Firestore Database"
  • Clique na aba "Regras"
  • Copie o conteúdo do arquivo firestore.rules do projeto
  • Cole no editor de regras do Firebase
  • Clique em "Publicar"
✅ Pronto! As regras de segurança estão configuradas.
8

Popular com 60 Casos de Uso

Para testar a aplicação, você precisa popular o banco com os 60 casos de uso:

Opção 1 - Script Automático (RECOMENDADO):

node seed-firestore.js

Opção 2 - Manual no Firebase Console:

  • No Firestore Database, clique em "Iniciar coleção"
  • ID da coleção: useCases
  • Adicione documentos manualmente com os campos necessários
9

Testar Aplicação!

Agora é só testar:

  • Salve o arquivo src/firebase/config.js
  • A aplicação vai recarregar automaticamente
  • Acesse: http://localhost:5173
  • Cadastre uma equipe com nome e email
  • Navegue pelos 60 casos de uso
  • Selecione um caso e veja a mágica acontecer! 🚀
🎉 Parabéns! Sua aplicação está configurada e funcionando!

🐛 Problemas Comuns

Erro: "Firebase not configured"

→ Você não configurou o arquivo src/firebase/config.js corretamente.

Erro: "Permission denied"

→ Você não publicou as Security Rules no Firestore.

Nenhum caso aparece na galeria

→ Você não populou a coleção useCases no Firestore.

Erro ao cadastrar equipe

→ Verifique se você habilitou Authentication com Email/Password.

🎯 Tudo Pronto!

Agora você tem uma aplicação completa de seleção de casos de uso com Firebase!
